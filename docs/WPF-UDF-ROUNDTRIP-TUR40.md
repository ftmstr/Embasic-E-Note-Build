# TUR 40 | WPF to UYAP A4 acceptance

EXP-007 exercises the same synthetic output through E-Note WPF and the
official Windows UYAP 5.4.20 editor. The WPF job keeps both cancellation
checks, destination refusal, the disabled secure note command, and
landscape refusal. It exports four literal Markdown paragraphs with an
unsaved edit, A4 portrait and asymmetric 17/23/19/27 mm margins. The test
copies the resulting archive only after the WPF scenarios pass. UYAP edits
a separate file and reopens it in a fresh JVM. The check compares the
expected text, four paragraphs, page size, orientation, all four margins and
the hash of the unedited WPF output. The existing direct-writer Markdown
and table/font fixtures continue to run independently.

## Physical Windows acceptance

Use a Release build at the stated HEAD in an interactive Windows 10 or 11
session, and a new local test directory. Save a UTF-8 Markdown note with a
heading, an empty line, and the text `Çığ ve İğdır — **Türkçe**`. Record
the SHA-256 of the note and any page settings sidecar. Open the note,
make an unsaved edit and create a new UDF copy on A4 portrait. Repeat by
cancelling each dialog and choosing an existing synthetic target. Record
file hashes and run the visible UI checks at 100% and 150% display scaling.

Use the separately installed official editor to reopen the copied UDF.
Record printer model and driver, paper size, orientation, page count,
margins and the presence of the edit if printing that copy. For any PDF
generated by the Windows print driver, record the PDF hash and inspect its
page dimensions, text and clipping. Evidence from printing via UYAP applies
to that editor. E-Note's W010 native printing and PDF acceptance requires
an actual E-Note print command and stays open on this branch.

Hosted WPF and editor automation are recorded separately from physical
Windows, DPI, printer, PDF and security tests.
